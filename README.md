# Task: Qwen Model Setup Using Google Colab and VS Code

## Objective

The objective of this task was to set up and run the **Qwen2.5-Coder-3B-Instruct-AWQ** language model using Google Colab and make it accessible for development and usage through Visual Studio Code.

## Task Description

The task involved configuring a Qwen coding model in a Google Colab environment and using the available GPU resources to run the model. The setup was then configured so that the locally installed Visual Studio Code environment could interact with the model.

## Model Used

**Model:** Qwen/Qwen2.5-Coder-3B-Instruct-AWQ

The model is a code-focused language model designed for programming-related tasks such as code generation, completion, and understanding.

## Technologies and Tools Used

* Python
* Google Colab
* NVIDIA GPU
* Qwen2.5-Coder-3B-Instruct-AWQ
* Visual Studio Code
* Hugging Face
* Git/GitHub

## Implementation

The following steps were performed during the setup:

1. Set up a Google Colab environment with GPU support.
2. Installed the required Python libraries and dependencies.
3. Downloaded and loaded the Qwen2.5-Coder model.
4. Configured the model to run using the available Colab GPU.
5. Tested the model by sending coding-related prompts.
6. Configured the connection between the Colab-hosted model and Visual Studio Code.
7. Tested the setup from Visual Studio Code to verify that the model could be accessed successfully.

## Result

The Qwen2.5-Coder model was successfully configured to run in the Google Colab environment, allowing the model to be used for coding-related tasks while using the Colab GPU resources.

## Conclusion

This task provided practical experience in deploying a local/open-source coding language model using cloud GPU resources and integrating it with a local development environment. It also involved working with Python dependencies, model configuration, GPU resources, and API-based communication between environments.
